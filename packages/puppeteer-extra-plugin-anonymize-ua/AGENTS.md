## Package Overview

This is `@zorilla/puppeteer-extra-plugin-anonymize-ua`, a plugin for the zorilla/puppeteer-extra framework that anonymizes user agents by removing headless browser signatures and optionally replacing platform information.

**Key Features:**
- Removes "HeadlessChrome" from user agent strings
- Optionally changes platform to Windows 10 64-bit (most common)
- Supports custom user agent transformation functions
- Works with both Puppeteer and Playwright through the puppeteer-extra plugin system

## Architecture

### Plugin Structure

This is a simple plugin with a single class that extends `PuppeteerExtraPlugin`:

**Core Implementation (`src/index.ts`):**
- `Plugin` class extends `PuppeteerExtraPlugin`
- Implements `name` getter returning `'anonymize-ua'`
- Implements `defaults` getter with default options
- Implements `onPageCreated()` lifecycle hook that modifies user agent

**User Agent Transformation Logic:**
The `onPageCreated()` hook performs these transformations in order:
1. Get current user agent from `page.browser().userAgent()`
2. If `stripHeadless` is true: Replace `HeadlessChrome/` with `Chrome/`
3. If `makeWindows` is true: Replace platform info `(...)` with `(Windows NT 10.0; Win64; x64)`
4. If `customFn` is provided: Apply custom transformation function
5. Call `page.setUserAgent()` with modified string

### Plugin Options

```typescript
interface PluginOptions {
  stripHeadless?: boolean;  // Default: true - Remove HeadlessChrome signature
  makeWindows?: boolean;    // Default: true - Set platform to Windows 10
  customFn?: ((ua: string) => string) | null;  // Default: null - Custom transformer
}
```

### Lifecycle Integration

This plugin only hooks into `onPageCreated()` - it doesn't modify launch options or other lifecycle events. The user agent is set on each new page as it's created, which ensures:
- Works for all pages including incognito contexts
- Applied before page navigation
- Uses fresh browser UA as base (preserves Chrome version)

## Testing Strategy

**Unit Tests (`test/index.test.ts`):**
- Basic plugin structure validation
- Option handling (defaults and custom)
- User agent transformation logic with mocked page objects

**Integration Tests (Skipped):**
- Located in `test/integration.test.ts.skip`
- Require full puppeteer-extra build to run
- Test actual browser automation scenarios

**Mock Pattern:**
Tests use mock page objects with this structure:
```typescript
const mockPage = {
  browser: () => ({
    userAgent: () => Promise.resolve(mockUserAgent),
  }),
  setUserAgent: vi.fn(),
} as unknown as Page;
```

## Type Safety Notes

- Uses `override` keyword on all methods that override base class (required by TypeScript strict mode)
- Properly typed with Puppeteer's `Page` type
- No manual `.d.ts` files - all types generated by TypeScript compiler
- Test mocks use `as unknown as Page` for type coercion (preferred over `as any`)

## Common Development Tasks

**Adding a new option:**
1. Add to `PluginOptions` interface
2. Add to `defaults` getter with default value
3. Add transformation logic in `onPageCreated()`
4. Add test cases for the new option
5. Update JSDoc comments

**Debugging user agent issues:**
Enable debug logging with:
```bash
DEBUG=puppeteer-extra-plugin:anonymize-ua node your-script.js
```

The plugin uses `this.debug('new ua', ua)` to log the transformed user agent.
